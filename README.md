# 🛒 BazarDor

BazarDor is a website where users can check the prices of daily products. Users can see product details, compare prices, and find products by category.

## Live Website

- Live Link: https://bazar-dor-neon.vercel.app/
- GitHub Repository: https://github.com/Ashraf-Mia/Bazar-Dor

## Features

- Responsive design for mobile, tablet, and desktop.
- View daily product prices.
- Browse products by category.
- See products with rising and falling prices.
- View product details and market prices.
- Sort products by price.
- Sign up and sign in with email and password.
- Sign in with Google and GitHub.
- Protected pages for logged-in users.
- Update profile information.
- Show loading states and error messages.
- Custom 404 page for invalid routes.
